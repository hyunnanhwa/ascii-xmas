# ASCII XMAS × NANA

문자(ASCII)로 3D 크리스마스 트리가 만들어지는 웹 애니메이션입니다.
아래 에디터에는 코드 전체가 처음부터 적혀 있고, 하이라이트가 한 줄씩 읽어 내려가며 화면이 만들어집니다.
빌드 도구 없이 정적 파일 3개(`index.html`, `style.css`, `script.js`)로 동작합니다.

## 연출 순서

하이라이트가 `scene.phase("...")` 줄에 닿는 순간 해당 단계가 시작됩니다.
트리·별·바닥·선물상자는 모두 3D 회전 무대 위에 있고, 살짝 위에서 내려다보는 시점으로 함께 돕니다.

1. 밤하늘 별 반짝임 + 눈 내리기 시작 (끝까지 계속 내림)
2. 원형 바닥(회전 무대) 등장, 회전 시작
3. 코드 글자가 3D 트리(여러 녹색이 섞인 울퉁불퉁한 가지 + 안쪽 잎 층)로 바뀌며 아래에서 위로 자라남
4. 골드·화이트 5겹 반짝이 띠가 아래에서 위로 감김
5. 빨강·골드 큰 구슬 오너먼트 14개가 반짝 빛나며 하나씩 나타남
6. 입체 오각별이 떨어져 꼭대기에 앉고 긴 빛줄기가 뻗어나감 (트리와 같이 회전)
7. 리본을 두른 작은 3D 선물상자 6개가 반짝이며 나타남
8. 전구 점등 + 눈이 더 풍성하게
9. MERRY CHRISTMAS 2026
10. 무대가 멈추며 선물상자 하나가 앞으로 나오고, 뚜껑이 열리면서 개구리가 튀어나와 말풍선으로 "앙기모띠!!"

## 조작

| 키 | 동작 |
| --- | --- |
| `R` | 처음부터 다시 재생 |
| `Space` | 일시정지 / 재생 |
| 속도 버튼 | 1× / 2× 전환 |

## GitHub Pages 배포

1. GitHub에서 새 저장소를 만들고 이 폴더의 파일을 그대로 올립니다.
   ```bash
   git init
   git add .
   git commit -m "ASCII Christmas Tree"
   git branch -M main
   git remote add origin https://github.com/<아이디>/<저장소이름>.git
   git push -u origin main
   ```
2. 저장소 **Settings → Pages** 로 이동합니다.
3. **Source**: `Deploy from a branch`, **Branch**: `main` / `/ (root)` 선택 후 저장합니다.
4. 1~2분 뒤 `https://<아이디>.github.io/<저장소이름>/` 에서 확인할 수 있습니다.

## 로컬에서 보기

`index.html`을 더블클릭해도 열리지만, 브라우저에 따라 로컬 파일에서 스크립트가 막힐 수 있어 간단한 서버를 권장합니다.

```bash
python -m http.server 8000
```

그다음 http://localhost:8000 으로 접속합니다.

## 수정 포인트 (`script.js` 상단)

- `CPS` — 코드 타이핑 속도 (초당 글자 수)
- `HOLD` — 각 단계 애니메이션이 재생되는 시간
- `baubles` 배열 길이 / `BAUBLE_HUES` — 오너먼트 개수와 색
- `FROG_BIG` — 상자에서 나오는 개구리 모양
- `TILT` — 내려다보는 각도 (클수록 위에서 보는 느낌)
- `MSG` — 하단 인사말
